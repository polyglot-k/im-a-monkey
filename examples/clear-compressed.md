# monkey-clear 예시: 압축된 채팅 설명

요청: "동료가 이렇게 적었는데 이게 무슨 말이야? 풀어서 설명해 줘." 읽는 사람은 이 서비스를 처음 보고, 읽고 나서 무엇을 확인할지 정하려고 해요.

## 전

<!-- monkey-lint: off -->
로그인 지연은 세션 저장소 TTL 만료 직전에 갱신 요청이 몰려 락 경합 생기고 커넥션 풀 고갈, 타임아웃 → 재시도 폭증 탓. TTL 늘리고 갱신 jitter 넣음. 효과는 미확인.
<!-- monkey-lint: on -->

## 후

로그인이 느려진 이유는 세션을 갱신하는 요청이 한꺼번에 몰렸기 때문이에요. 이 수정이 실제로 효과가 있는지는 아직 확인하지 못했어요.

세션 저장소는 로그인 상태를 일정 시간만 기억해요. 그 시간(TTL)이 끝나기 직전에 사용자들의 갱신 요청이 같은 순간에 들어와요. 요청들이 같은 세션 정보를 동시에 고치려고 서로 기다려요(락 경합). 기다리는 요청이 데이터베이스 연결을 붙든 채 있어서 연결이 모자라게 돼요(커넥션 풀 고갈). 연결을 얻지 못한 요청은 시간 초과로 실패해요. 실패한 요청을 클라이언트가 다시 보내서 요청이 더 늘어나요(재시도 폭증).

동료가 고친 것은 두 가지예요. 기억하는 시간(TTL)을 늘렸고 갱신 시각을 조금씩 어긋나게 흩뜨렸어요(갱신 jitter). 늘린 시간이 얼마인지는 글에 없어서 `<채울 값>`이에요. 동료에게 물어보면 돼요.

## 무엇을 바꿨나

<!-- monkey-lint: off -->
- 결론 먼저: 첫 문단에 원인과 아직 모르는 것을 둬요. 배경부터 쌓지 않아요.
- 화살표 하나가 한 문장: "락 경합 → 커넥션 풀 고갈 → 타임아웃 → 재시도 폭증"을 네 문장으로 풀었어요(W01).
- 사람 말이 먼저, 식별자는 뒤: "시간이 끝나기 직전", "(TTL)"처럼 써요(T02).
- 용어 목록을 앞에 세우지 않고 처음 나오는 문장 안에서 풀었어요.
- "효과는 미확인"은 "해결됐다"로 바꾸지 않았어요. 원문에 없는 시간 값도 지어내지 않았어요.
