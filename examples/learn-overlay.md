# monkey-learn 예시: 지적을 오버레이에 남기기

## 사용자의 지적

<!-- monkey-lint: off -->
"방금 설명에 약어가 세 개 연달아 나와서 못 읽겠어. 이런 건 다음부터 풀어서 써 줘. 규칙으로 남겨."

문제가 된 문장: "배포 때 CDN 캐시 TTL 때문에 롤아웃이 지연돼."
<!-- monkey-lint: on -->

## 판단

문제를 한 문장으로 쓰면 "처음 나온 약어와 식별자를 풀지 않고 한 문장에 여러 개 넣었다"예요. 카탈로그에 있는 W01(압축 설명)과 같은 패턴이라서 새 ID를 만들지 않고 W01 아래에 사례만 붙여요.

## 오버레이에 추가한 줄

파일: `~/.config/im-a-monkey/overlay/antipatterns.md`

```
### W01 압축 설명
- 사례: 약어 세 개를 풀지 않고 한 문장에 둠("A 캐시의 만료 시간 때문에 B 배포가 늦어진다") → 사람 말로 단계마다 한 문장씩, 약어는 처음 나오는 문장에서 한 번 풀기
```

`monkey-human`이 다음 진단부터 이 파일을 함께 읽어요.

## 지킨 것

<!-- monkey-lint: off -->
- 고유 정보를 일반적인 말로 바꿨어요. 지적받은 문장 그대로가 아니라 어떤 문장에도 적용되는 모양으로 적었어요.
- 정규식은 만들지 않았어요.
- 저장소의 `catalog/`와 `skills/`는 건드리지 않았어요. 쓴 곳은 사용자 오버레이뿐이에요.
<!-- monkey-lint: on -->
