# 매체별 렌더 표

매체가 달라도 독자가 받는 의미는 같아야 한다. 이 표는 같은 의미를 매체마다 어떤 문법으로 쓰는지 정한다. "렌더 확인 필요"는 이 문서를 쓸 때 확신하지 못한 칸이다. 그 칸을 쓴 그림은 렌더 체크리스트에서 "못 봄"으로 두고 사용자에게 알린다.

## 그림

| 매체 | 흐름·시퀀스·상태 그림 | 캡션 |
|---|---|---|
| Obsidian | `mermaid` 코드 블록을 그대로 렌더한다 | 그림 다음 줄에 일반 문단으로 `그림 N. 질문?` |
| GitHub (README, 이슈, PR) | `mermaid` 코드 블록을 그대로 렌더한다. 위키는 렌더 확인 필요 | 그림 다음 줄에 일반 문단, 기울임(`*그림 N. 질문?*`)도 된다 |
| HTML | 인라인 `<svg>`로 그린다. Mermaid를 쓰려면 스크립트를 따로 불러야 하므로 기본은 SVG다 | `<svg>` 바로 다음 줄에 `<p>그림 N. 질문?</p>`. `<figure>`·`<figcaption>`으로 묶어도 된다 |
| Notion | 코드 블록 언어를 Mermaid로 고른 뒤 코드/미리보기 전환이 필요하다. 렌더 확인 필요. 마크다운을 붙여 넣을 때 자동으로 바뀌는지도 렌더 확인 필요 | 그림 블록 바로 아래 텍스트 블록 |

- 그림 문법이 매체에서 안 되면 번호 목록이나 표로 바꾼다. 캡션 규칙은 표에도 그대로 쓴다.
- 이미지 파일(`![설명](경로)`)도 그림이다. 대체 텍스트에는 그림이 답하는 내용을 한 문장으로 쓴다.

## 콜아웃 5종

| 의미 | Obsidian | GitHub | HTML | Notion |
|---|---|---|---|---|
| 결론 | `> [!summary] 결론` | `> [!NOTE]` 다음 줄 본문을 "결론:"으로 시작 | `<aside>` 안 첫 단어 "결론:" | 콜아웃 블록, 첫 단어 "결론:" |
| 주의 | `> [!warning] 주의` | `> [!WARNING]` 다음 줄 본문을 "주의:"로 시작 | `<aside>` 안 첫 단어 "주의:" | 콜아웃 블록, 첫 단어 "주의:" |
| 예시 | `> [!example] 예시` | `> [!TIP]` 다음 줄 본문을 "예시:"로 시작 | `<aside>` 안 첫 단어 "예시:" | 콜아웃 블록, 첫 단어 "예시:" |
| 결정 필요 | `> [!question] 결정 필요` | `> [!IMPORTANT]` 다음 줄 본문을 "결정 필요:"로 시작 | `<aside>` 안 첫 단어 "결정 필요:" | 콜아웃 블록, 첫 단어 "결정 필요:" |
| 참고 | `> [!note] 참고` | `> [!NOTE]` 다음 줄 본문을 "참고:"로 시작 | `<aside>` 안 첫 단어 "참고:" | 콜아웃 블록, 첫 단어 "참고:" |

- GitHub 알림은 종류가 다섯 개로 고정이고 제목을 바꿀 수 없다. 그래서 의미는 본문 첫 단어로 밝힌다. `[!NOTE]` 같은 표시 줄에는 다른 글자를 붙이지 않는다.
- Notion에 마크다운 `> [!...]`를 붙여 넣으면 콜아웃 블록이 되는지는 렌더 확인 필요다. 안 되면 콜아웃 블록을 직접 만든다.
- 아이콘과 색은 매체 기본값을 쓴다. 의미는 언제나 첫 단어가 전한다.

## 신뢰도 배지 3종

| 배지 | 뜻 | 네 매체 공통 |
|---|---|---|
| `[측정]` | 직접 재거나 로그·쿼리로 확인한 값 | 값 바로 뒤에 글자 그대로 쓴다 |
| `[추정]` | 근거는 있지만 재지 않은 값 | 같다 |
| `[미확인]` | 들은 값이거나 확인할 방법이 아직 없는 값 | 같다 |

- 대괄호 글자는 네 매체 모두 그대로 글자로 보인다. 바로 뒤에 `(`를 붙이면 링크로 읽히므로 띄어 쓴다.
- HTML에서 `<span>`으로 꾸며도 글자는 남긴다. 색만 있는 배지는 쓰지 않는다.

## 색과 기호

색의 의미는 고정한다. 색을 못 보는 독자, 흑백 출력, 색을 지원하지 않는 매체에서도 같은 뜻이 되도록 기호를 함께 쓴다.

| 의미 | 색 | 기호 |
|---|---|---|
| 추가 | 초록 | `+` |
| 제거·위험 | 빨강 | `−` |
| 변경 | 노랑 | `~` |
| 그대로·나머지 | 무채색 | 기호 없음 |

| 매체 | 색을 입히는 법 | 색 없이 구분하는 법 |
|---|---|---|
| Obsidian | Mermaid `classDef`와 `class`로 바뀐 노드만 칠한다 | 노드 이름 앞에 `+`, `−`, `~` |
| GitHub | Mermaid `classDef`. 표에는 색을 못 넣는다. `diff` 코드 블록은 `+`·`-` 줄을 색으로 보여 준다 | 표에 "변화" 열을 두고 `+`, `−`, `~`를 쓴다 |
| HTML | SVG `fill`·`stroke`나 CSS 클래스 | 글자 기호를 함께 쓰고 선 모양(실선·점선)도 구분에 쓸 수 있다 |
| Notion | 글자색·배경색 | 표에 "변화" 열과 기호. Mermaid 색 지정은 렌더 확인 필요 |

- `diff` 코드 블록의 제거 표시는 ASCII `-`여야 색이 입혀진다. 문장과 표에서는 `−`를 써도 된다.
- 강조는 차이에만 쓴다. 바뀌지 않은 항목에 색·볼드·기호를 붙이면 차이가 묻힌다.
