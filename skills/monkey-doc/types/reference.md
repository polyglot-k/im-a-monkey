# 레퍼런스 (reference)

- 언제: 독자가 필요할 때 값 하나를 찾아본다. 설정, API 필드, 오류 코드.
- 블록 순서: 결론 → 용어표 → 예시 → 코드 읽기 지도
- 길이감: 80~500 어절 (상한 초과 → 주제별로 레퍼런스를 나눈다, 하한 미만 → 기본값·허용 범위·예시가 빠졌는지 본다)
- 자세함: 항목마다 이름 · 뜻 · 기본값 · 허용 범위. 이유와 역사는 쓰지 않는다. 코드에서 다시 만들 수 있는 목록은 복사하지 않고 원본 위치를 가리킨다.
- 가독성 장치: 맨 위 한 줄(무엇을 찾는 문서인지), 정해진 정렬 순서. 섹션별 한 줄 결론은 쓰지 않는다.
- 요소:
  - 각주: 선택 — 예외 값 설명이 길 때 표 칸을 짧게 두려고.
  - 표: 쓴다 — 레퍼런스의 본체다.
  - 그림: 쓰지 않는다 — 값을 찾는 독자에게 그림은 지나쳐야 하는 길이다.
  - 콜아웃: 선택 — 잘못 바꾸면 크게 깨지는 값 하나에 "주의".
  - 접기: 쓰지 않는다 — 접힌 칸은 찾기(Ctrl+F)에 걸리지 않을 수 있다.
  - 용어표: 쓴다 — 이름에서 뜻으로 가는 길이 이 문서의 목적이다.
  - 코드 지도: 쓴다 — 값의 원본 위치를 SHA로 고정해 둔다.
- 이 유형에 넣지 않는 것: 사용법 안내(How-to로 나눈다), 설계 이유, 시간에 묶인 말.

## 쓰는 법

- 정렬 기준(가나다, 알파벳, 쓰는 순서)을 하나 정해 맨 위 한 줄에 밝힌다.
- 같은 열에는 같은 단위를 쓴다. 단위가 섞이면 열 이름에 단위를 붙인다.
