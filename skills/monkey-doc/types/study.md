# 학습 교보재 (study)

- 언제: 독자가 시간을 들여 개념을 익히고, 다 읽은 뒤 스스로 쓸 수 있게 된다.
- 블록 순서: 결론 → 예시 → 흐름 그림 → 절차 → 점검 질문 → 용어표
- 길이감: 400 어절~없음 (상한 없음 — 길어지면 단원으로 나눈다, 하한 미만 → 예시·흔한 오해·직접 해 보기가 빠졌는지 본다)
- 자세함: 단계마다 왜 그런지 풀고, 흔한 오해를 하나씩 다룬다. 예시는 실제 값으로 끝까지 따라간다. 직접 해 보는 단계에는 기대 결과를 쓴다.
- 가독성 장치: 단원마다 맨 위에 "이 단원을 마치면 할 수 있는 것" 한 줄, 섹션별 한 줄 결론, 점검 질문의 답은 접기.
- 요소:
  - 각주: 선택 — 더 깊이 볼 사람을 위한 곁가지. 본문만 읽어도 이해가 끝나야 한다.
  - 표: 선택 — 비슷한 개념을 나란히 구분할 때.
  - 그림: 쓴다 — 처음 배우는 사람은 구조를 그림으로 먼저 잡는다. 단원마다 하나 이상.
  - 콜아웃: 쓴다 — "예시"와 "주의"(흔한 오해). 섹션마다 두 개 이하.
  - 접기: 쓴다 — 점검 질문의 답. 먼저 생각해 보게 한다.
  - 용어표: 쓴다 — 맨 끝에 복습용으로. 본문에서는 처음 나올 때 문장 안에서 푼다.
  - 코드 지도: 선택 — 실습 코드가 있을 때.
- 이 유형에 넣지 않는 것: 결정 요청, 정답만 늘어놓은 요약, 앞머리 용어 사전.

## 쓰는 법

- 단원 하나는 개념 하나다. 단원 끝에 점검 질문 두세 개를 둔다. 본문을 되묻지 않고 다른 상황에 적용하게 묻는다.
- 처음 배우는 독자를 기준으로 예시를 정의보다 앞에 둔다.
