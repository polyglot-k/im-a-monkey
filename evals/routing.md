# 모호한 요청 라우팅 세트

README의 설치 검증은 스킬마다 분명한 문구 하나씩만 썼어요. 여기는 두 스킬이 다툴 만한 요청 18개예요. 기대 스킬은 각 스킬의 `description`에 적힌 경계로 정했어요. `python3 evals/route.py`로 돌려요.

| 요청 | 기대 스킬 | 이유 |
|---|---|---|
| 이 문서 다듬어줘: 배포는 금요일에 하기로 했고, 그전에 테스트가 끝나야 한다고 합니다. | monkey-human | 구조는 두고 문장만 고치는 요청이에요. |
| 이 문서 구조 다시 잡아줘: 배포 일정, 테스트 범위, 담당자 이야기가 한 문단에 섞여 있어요. | monkey-doc | 구조를 다시 잡는 요청은 monkey-doc 몫이에요. |
| 이 설명 너무 어려워, 다시 해줘: 락 경합 때문에 커넥션 풀이 고갈돼서 타임아웃이 연쇄했다. | monkey-clear | 압축된 설명을 사람에게 풀어 달라는 요청이에요. |
| 이거 표로 비교해 줘: A안은 120ms, B안은 80ms, C안은 95ms | monkey-visual | "표로 비교해 줘"가 monkey-visual 문구에 그대로 있어요. |
| 팀에 공유할 정리 좀: 오늘 회의에서 일정은 한 주 미루고 담당은 그대로 두기로 했어요. | monkey-doc | 팀에 공유할 글은 문서 요청이에요. |
| AI 같아 보여, 다음엔 이러지 마 | monkey-learn | 지적에 "다음엔 이러지 마"가 붙었으므로 남기라는 말이에요. |
| AI 같아?: <!-- monkey-lint: off -->이번 프로젝트를 통해 많은 것을 배울 수 있었으며, 앞으로도 지속적으로 발전하겠습니다.<!-- monkey-lint: on --> | monkey-human | 남기라는 말 없이 AI 티만 묻는 요청이에요. |
| 말투 좀 부드럽게 | monkey-voice | 글이 없으니 대화 말투를 바꾸는 요청이에요. |
| 이 글 말투 좀 부드럽게 해줘: 해당 건은 금일 중 처리 예정이므로 참고 바랍니다. | monkey-human | 고칠 글이 붙어 있으니 문장 다듬기예요. |
| 이 흐름을 설명해 줘: 요청이 오면 큐에 쌓고, 워커가 하나씩 꺼내 처리한 뒤 결과를 저장한다. | monkey-clear | 그림 말 없이 말로 풀어 달라는 요청이에요. |
| 이 흐름을 그림으로: 요청이 오면 큐에 쌓고, 워커가 하나씩 꺼내 처리한 뒤 결과를 저장한다. | monkey-visual | 그림을 요청했어요. |
| 이 구조 다음에도 쓰자: 배경, 결정, 남은 일 순서로 쓴 회의록이에요. | monkey-learn | 구조를 저장해 두자는 말이에요. |
| 이 글 번역투 같아: 그것은 매우 중요한 것으로 여겨지는 것이 사실이다. | monkey-human | 남기라는 말 없이 번역투만 지적했어요. |
| 이제 존댓말 말고 편하게 말해 줘 | monkey-voice | 대화 말투 전환이에요. |
| 지난주 결제 장애를 보고서로 만들어 줘: 카드사 응답 지연으로 20분간 승인이 실패했어요. | monkey-doc | 장애 보고서는 monkey-doc 문구예요. |
| 이 글 읽기 편하게 고쳐 줘: 본 사안은 상기 일정에 의거하여 익주 중으로 조치될 예정입니다. | monkey-human | 고칠 글이 붙었고 구조 얘기가 없어서 문장 다듬기예요. |
| 이 메모 정리 좀 해줘: 일정 밀림, 담당 변경 없음, 테스트는 목요일 | monkey-doc | 메모를 읽을 글로 정리하는 요청이에요. 문장 다듬기가 아니에요. |
| 이거 비교해서 한눈에 보이게 해줘: 캐시 적중률 A 92%, B 78%, C 85% | monkey-visual | 한눈에 보이게 하는 시각화 요청이에요. |
