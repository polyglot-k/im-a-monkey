- 문서(제목·섹션이 여러 개인 글, 파일)를 만들지 않고 채팅에서 바로 답하는가. 표 하나와 짧은 문장 몇 줄로 끝나면 이긴다. 질문하는 사람이 바로 팀원에게 전달할 수 있는 형태인가.
- 세 등급의 값(25원, 12원 + 꺼낼 때 10원, 4원, 3~5시간, 30일, 90일)이 원문과 같은가. 계산한 값(예: 월 비용)을 보탰다면 계산이 맞고 계산했다고 밝히는가.
- 원문의 조건(하루 20GB, 지난 30일 치를 가끔 꺼냄)에 비춰 무엇이 맞는지 한두 문장으로 답하는가. 원문에 없는 가정을 깔았다면 가정이라고 밝히는가.
- 볼드·이모지·소제목 같은 장식이 적은가.
