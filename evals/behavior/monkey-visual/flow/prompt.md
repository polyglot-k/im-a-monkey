파일 업로드 기능의 README에 "업로드가 어디서 멈출 수 있나" 섹션을 넣으려고 해. GitHub에서 보는 문서야. 처리 흐름을 그림으로 보여 주고 설명도 붙여 줘.

처리 순서:
1. 사용자가 파일을 올린다.
2. 크기를 검사한다. 50MB를 넘으면 거절하고 사용자에게 "파일이 너무 큼"을 알린다.
3. 확장자를 검사한다. jpg, png, pdf가 아니면 거절하고 "지원하지 않는 형식"을 알린다.
4. 악성 코드 검사를 한다. 걸리면 파일을 격리 저장소로 옮기고 관리자에게 알린다. 사용자에게는 "검사 중 문제 발견"만 알린다.
5. 이미지(jpg, png)면 썸네일을 만든다. pdf는 이 단계를 건너뛴다.
6. 저장소에 저장하고 사용자에게 "업로드 완료"를 알린다.

참고: 악성 코드 검사는 평균 2초 걸린다고 들었는데 직접 재 보지는 않았다.
