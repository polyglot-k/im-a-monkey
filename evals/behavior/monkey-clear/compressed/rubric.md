- 원문의 인과 단계(파드가 늘어남 → 새 파드는 미리 맺어 둔 DB 연결이 없음 → 첫 요청마다 연결을 새로 맺음 → DB 연결 한도에 가까워져 기다림이 생김 → 응답이 늦어짐)를 한 문장에 한 단계씩 순서대로 풀었는가. 여러 단계를 한 문장에 접은 답은 진다.
- 결론(배포 직후 느려진 이유와 대응)이 맨 앞에 있는가.
- p99, HPA, 파드, 커넥션 풀, max_connections, readiness, minReplicas 같은 말을 쓸 때 사람 말 설명을 먼저 두고 식별자를 뒤에 붙였는가. 풀이 없이 식별자만 남긴 답은 감점한다.
- 원문의 두 대응(준비 완료 전에 연결 미리 맺기, 최소 대수 4→6)과 "효과는 아직 확인 전"이라는 점을 빠뜨리지 않았는가. 짧게 줄이려고 필요한 맥락을 버린 답은 감점한다.
- 원문에 없는 원인이나 효과를 단정해서 덧붙이지 않았는가.
